Important info:

- one digit name of a file (like, e.g. 3.txt) means that the it contains info about 
  an algorithm which should be implemented, and which will produce results for symulator
- two digit name (like, e,g. 21.txt) means that the file contains already results which 
  can be used directly by the symulator
- three digit name (like, e.g. 100.txt, 200.txt) means that the boat is controlled by a
  specific set of H, P, PR, V providing some expected (or known in literaturę behawior),
  e.g.
      100.txt - 'Optimal solution for boss":  the set of H, P, PR, V provides optimal
                  solution for a boss 
      200.txt - "Enlightened tyrany" (oswiecona tyrania) - players agree about the set 
                 of H, P, V which  provides optimal
                  solution for a boss, but at each new game the agree to set a new boss
      300.txt - ….
